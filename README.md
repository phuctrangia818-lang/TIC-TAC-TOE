# Tic-Tac-Toe Game

A classic Tic-Tac-Toe game built with HTML, CSS, and vanilla JavaScript.

## Demo

> Open `tic-tac-toe.html` in your browser to play instantly — no installation needed.

## Features

- Two-player turn-based gameplay (X and O)
- Detects win conditions for all rows, columns, and diagonals
- Detects draw when all squares are filled
- Displays current turn and game result
- Click any square after the game ends to start a new game
- Sound effect on each move

## How to Play

1. Player **X** always goes first
2. Take turns clicking empty squares to place your mark
3. First player to get **3 in a row** (horizontally, vertically, or diagonally) wins
4. If all 9 squares are filled with no winner, the game is a **draw**
5. Click any square after the game ends to **reset the board**
